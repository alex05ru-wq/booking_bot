# Telegram-бот записи клиентов «Барбершоп»

Бот для онлайн-записи в барбершоп, салон красоты, автосервис или любой бизнес с записью по времени. Клиент сам выбирает услугу, день и свободное время, владелец получает уведомление о каждой записи.

## Возможности

**Для клиента**
- Меню с кнопками: «Записаться», «Мои записи», «Услуги и цены», «Контакты»
- Запись в несколько нажатий: услуга → день → время → имя → телефон → подтверждение
- Показывается только свободное время с учётом длительности услуги
- Номер телефона можно отправить одной кнопкой
- Просмотр и отмена своих записей

**Для владельца**
- Уведомление в Telegram о каждой новой записи и отмене
- Команды `/today`, `/tomorrow`, `/week` — расписание на день и неделю

**Надёжность**
- Два клиента не смогут записаться на одно время (проверка под блокировкой)
- Нельзя записаться на прошедшее время или «через 5 минут»
- Выходные дни и рабочие часы учитываются автоматически
- Записи хранятся в базе SQLite и не теряются при перезапуске

## Настройка под свой бизнес

Всё меняется в одном файле `config.py`, код трогать не нужно:
- название, адрес, телефон;
- список услуг с ценами и длительностью;
- рабочие часы и дни недели;
- шаг сетки времени и на сколько дней вперёд открыта запись.

## Технологии

- Python 3
- pyTelegramBotAPI — Telegram Bot API, inline- и reply-клавиатуры
- SQLite — хранение записей
- threading.Lock — защита от одновременной записи
- zoneinfo — часовой пояс (бот работает правильно на сервере в любом поясе)
- python-dotenv — секреты в .env

## Установка и запуск

1. Клонируй репозиторий:
```bash
git clone https://github.com/alex05ru-wq/booking_bot.git
cd booking_bot
```
2. Установи зависимости:
```bash
pip install -r requirements.txt
```
3. Создай бота через @BotFather и получи токен.
4. Создай файл `.env` по образцу `.env.example`:
```
BOT_TOKEN=токен_от_BotFather
ADMIN_ID=
TIMEZONE=Europe/Moscow
```
5. Запусти бота:
```bash
python bot.py
```
6. Напиши боту `/myid`, впиши полученное число в `ADMIN_ID` в файле `.env` и перезапусти бота — теперь уведомления о записях будут приходить тебе.
